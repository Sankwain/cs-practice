# Git: основные понятия

## Рабочая папка (working directory)
Это папка на твоём компьютере, где ты редактируешь файлы. Здесь ты создаёшь, изменяешь и удаляешь файлы. Git отслеживает изменения именно в этой папке.

## Индекс (staging area)
Это промежуточная область между рабочей папкой и коммитом. Сюда ты добавляешь файлы командой git add, чтобы сказать Git: "именно эти изменения я хочу сохранить в следующем коммите". Индекс позволяет собирать коммит частями, не сохраняя всё подряд.

## Коммит (commit)
Это снимок состояния файлов на определённый момент времени. Коммит сохраняет то, что было добавлено в индекс. У каждого коммита есть уникальный хеш, автор, дата и сообщение. Коммиты образуют историю проекта.
