# Воркшоп lab03: история, сравнение, восстановление

## Различия между git diff, git show и git log

- **git diff** — показывает различия между двумя состояниями (рабочая папка vs индекс, или два коммита). Не показывает метаданные коммита (автора, дату, сообщение).
- **git show** — показывает **один конкретный коммит** целиком: метаданные (автор, дата, сообщение) и изменения, которые он внёс. Удобно для просмотра "что именно было в этом коммите".
- **git log** — показывает **историю коммитов** (список). Не показывает сами изменения, только кто, когда и с каким сообщением делал коммит. С флагом --stat добавляет статистику изменений.

## Что нашли git log -S и git blame

- **git log -S"def"** — нашёл все коммиты, в которых изменилось количество вхождений строки "def" в файле. То есть показал моменты, когда добавлялись новые функции.
- **git blame** — для каждой строки файла показал, в каком коммите и кем она была добавлена. Позволяет отследить историю каждой строки.
